# V15 版本修正提纲

V15 总体继续保留 V14 已验证有效的 **强 SFT → PPO** 主线，不重构现有训练框架，主要进行以下四项修改。

## 1. Q-Critic + Seat-local Q-Boosting

将 V14 的：

```text
V(s) + GAE
```

修改为：

```text
Q(s,a) + Seat-local Q-Boosting
```

主要目的：

- 降低不完全信息 self-play 中 Advantage 的额外方差；
- 提高 PPO policy-gradient 信号质量；
- 保留当前 `pending[env][seat]` 的 per-seat trajectory，不重构 full joint trajectory；
- Critic 不增加新的 query，继续使用现有 `value_query`，最终由 `Linear(192,241)` 输出所有动作的 Q-value；
- PPO clipped objective 等主体框架保持不变。

**具体算法、公式、Critic 结构及代码修改方案请参考audit/reports/v15_ppo_20260814/V15 Q-Boosting 简要设计.md文档。**

---

## 2. Actor Offense / Defense Query 修正

V14 每个合法动作已经具有：

```text
offense_query(a)
defense_query(a)
```

但最终 Policy MLP 只直接使用 Defense Query hidden。

V15 增加 Offense Query 到最终 action scoring 的直接通路：

```text
offense_hidden
    ↓
zero-init projection
    +
defense_hidden
    ↓
原 policy_head
    ↓
logit(a)
```

新增 Offense 通路采用 zero initialization，使 V15 初始化时保持原 SFT Policy 输出不变，再由 PPO 学习如何使用 offense representation。

---

## 3. 增加半庄最终排名 Reward

继续保留 V14 的小局点棒变化 reward：

```text
reward_kyoku =
clip(point_delta / 1000, -24, +24)
```

在整个半庄真正结束的最后一个小局额外加入：

```text
1位   +12
2位    +6
3位    -6
4位   -12
```

即：

```text
普通小局：
reward = kyoku_point_reward

半庄最终小局：
reward =
kyoku_point_reward
+
hanchan_rank_reward
```

目的：

> 在继续利用局级 point-delta 高质量学习信号的同时，让 PPO 开始直接优化完整半庄的最终排名目标。

---

## 4. KL 与后期训练稳定性调整

### PPO old-new KL

V15 第一版保持 V14：

```yaml
ppo_clip: 0.20
target_kl: 0.020
```

目前没有证据表明 V14 的主要瓶颈是单次 PPO 更新幅度不足，因此暂不放宽到 `0.025`。

### SFT Reference KL

V14 使用约：

```text
0.02 → 0.002
```

V15 考虑减弱早期约束，同时加强后期防漂移能力。

推荐采用轻微 U-shaped schedule：

```text
Early:   0.010
   ↓
Middle:  0.002
   ↑
Late:    0.005
```

设计目标：

```text
早期：
保护强 SFT initialization

中期：
允许 PPO 明显偏离 SFT 并学习更强策略

后期：
提供较弱的 SFT anchor，降低无意义 Policy drift
```

同时继续利用 Actor LR decay 控制训练后期更新幅度。

# V15 最终核心变化

```text
V14
│
├── V(s) + GAE
├── Defense-only final scoring
├── Kyoku point reward
└── SFT KL 逐渐减弱
        │
        ▼
V15
│
├── Q(s,a) + Seat-local Q-Boosting
├── Offense + Defense final scoring
├── Kyoku point reward
│       +
│   Hanchan rank reward [12,6,-6,-12]
└── 更合理的 KL / 后期 Policy Drift 控制
```

V15 **不再加入 Actor Belief Auxiliary Learning**。

总体目标是：

> 在 V14 已经显著超过强 SFT 的基础上，通过更高质量的 Advantage estimator、完整半庄目标、Actor action-scoring 修正以及更合理的后期稳定机制，进一步提高 PPO 的竞技上限。
