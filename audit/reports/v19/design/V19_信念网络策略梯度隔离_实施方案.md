# V19 信念网络策略梯度隔离（监督单源）实施方案

> 状态：已实施（2026-09-06；代码、测试与文档均已按本文落地，提交记录见
> `audit/reports/v19/report/PROGRESS.md` 阶段 8）。
> 背景：V19 SFT/PPO 联合训练中，策略/BC 损失当前会经 30 个信念 token 回传
> `token_matrix → summary → 信念五头 → 1 层信念 backbone → public backbone`，
> 同时 PPO 的逐动作读出又额外回传一次；这使策略损失从“信念网络”和“策略网络”
> 两条路径同时更新三层共享层，实测表现为验证集 `belief_wait_loss` / 
> `belief_loss_total` 随训练波动上升、wait 头训练/验证差距扩大。

---

## 1. 现状与问题（必须修正）

### 1.1 当前梯度路径（旧）

| 路径 | 链路 | 现状 |
|---|---|---|
| 监督损失 | L_k → 五头 → 信念 backbone → shared_for_belief → public_backbone | 正确，×0.25 |
| 策略/BC 损失（token 路径） | policy → actor backbone → query 读 belief tokens → **token_matrix → summary → 五头 → 信念 backbone** → shared_for_belief → encoder | **错误**：策略损失穿透了整个私有信念网络 |
| 逐动作读出 | readout(21 维 → d_model) → pair_hiddens → policy | SFT detach；**PPO 不 detach**，策略损失再穿透信念网络一次 |

### 1.2 问题后果（实测证据，step 3000–15000）

- `validation/belief_loss_total`：9.29 → 9.18 → 9.56 → 9.98 → 9.71（波动偏大）；
- 贡献主要来自 `validation/belief_wait_tile_loss`：6.86 → 6.79 → 7.18 → 7.59 → 7.34；
- 同期 `train/belief_wait_tile_loss`：6.83 → 5.01 → 4.74 → 4.60 → 4.61（训练集持续下降）；
- 策略本身泛化正常：`validation/policy_ce 0.745→0.590`，`top1 0.729→0.778`；
- 结论：wait 头过拟合/校准漂移，且总损失被单头主导，与“策略损失污染信念网络”的梯度结构一致。

---

## 2. 目标（已确认的硬性要求）

1. **策略损失不得以任何形式传回 `token_matrix` 之后的私有信念网络**（五头 + 1 层 backbone + belief_query）。
2. **信念网络（一层 backbone 与五头）的更新梯度完全来自五个监督标签**，SFT 与 PPO 一致。
3. **五头监督损失按 `belief_public_grad_scale=0.25` 传回三层共享层**，SFT 与 PPO 一致。
4. 调整/均衡五个信念头损失比例：**建议调整**，见 §7。

---

## 3. 目标梯度路径（修正后）

| 路径 | 链路 | 处置 |
|---|---|---|
| 五头监督损失 | L_k → 五头 → 信念 backbone → shared_for_belief → public_backbone | 唯一更新信念网络的路径；共享层边界 ×0.25 |
| 策略/BC 损失（token 路径） | policy → actor backbone → query 读 belief tokens → **token_matrix** → 输入为 **detach(summary)** | `token_matrix` 仍接收策略梯度；**不再进入五头/backbone** |
| 逐动作读出 | readout(21 维 → d_model) → pair_hiddens → policy | 读出投影接收 actor 梯度；**输出特征恒 detach**，不回传信念网络 |
| 策略主路径 | policy → actor backbone → shared_hidden → encoder | 不变，正常 ×1.0 |

要点：

- `token_matrix` 仍是“信念 → token”接口，只由 actor/policy 梯度训练，监督损失不经过 token 路径（与既有决策一致）。
- 信念网络（五头 + backbone + belief_query）只由五头监督标签训练。
- 共享层梯度来源 = policy ×1.0 + critic ×0.25 + belief 监督 ×0.25，不再出现“策略经信念网络重复回传”。

## 4. 代码改动清单

### 4.1 `riichi_ppo_v1/model/belief_network.py`

- 在 `forward()` 生成 `belief_tokens` 前，对 `summary` 做 `.detach()`：
  ```python
  summary_for_tokens = summary.detach()
  summary_flat = summary_for_tokens.reshape(-1, SUMMARY_DIM)
  belief_tokens = self.token_matrix(summary_flat).view(...)
  ```
- `belief_summary` 仍返回原始（未 detach）张量；当前训练/评测没有消费它的监督梯度路径，若未来有使用需按用途确认。

## 7. 是否调整五个信念头损失比例（用户问题 4）

**初始标定已落地（2026-09-06）：wait=0.8、shanten=1.0、hand=1.0、
danger=3.0、loss=3.0，已写入 `v19_sft.yaml` / `v19_ppo.yaml` /
`training.yaml` 与 SFT 默认配置；同日关闭 wait_tile BCE
（`belief_wait_tile_weight=0.0`），wait 头只保留听牌/非听二判，故权重从 0.25
回调至 0.8；终值待复训后按验证曲线确认。**

### 7.1 当前问题（历史等权状态，已被初始标定取代）

- 五个头等权 `λ_k=1.0`，但原始损失尺度差异极大：
  | 头 | 典型验证损失（step 9000–15000） | 量级 |
  |---|---|---|
  | wait | 7.1–7.9（其中 tile 6.8–7.6） | 主导 |
  | shanten | 1.24–1.26 | 次 |
  | hand | 0.73–0.74 | 次 |
  | danger | 0.12–0.13 | 小 |
  | loss | 0.0041–0.0042 | 极小 |
- 等权会让总损失被 wait 头主导，wait 头的过拟合/波动直接决定 `belief_loss_total` 曲线。

### 7.2 推荐做法

1. **先完成梯度隔离**，重跑 2 步 CPU smoke + 首次 3000 步验证，再记录五个头在验证集上的损失尺度。
2. **手动标定权重（首选，简单可控）——已落地**：
   - 目标：各头对加权和监督损失的贡献大致同量级；
   - 初始标定值（阶段 10 修订：wait_tile BCE 关闭，wait 只剩听牌二判）：
     ```yaml
     belief_head_weight_wait: 0.8        # wait_tile 关闭后回调；听牌/非听仍重要
     belief_head_weight_shanten: 1.0
     belief_head_weight_hand: 1.0
     belief_head_weight_danger: 3.0      # danger 损失小，略放大
     belief_head_weight_loss: 3.0        # loss 归一化后归一阶小，按验证再调
     belief_wait_tile_weight: 0.0        # 未知局面逐牌等待过于随机，关闭
     ```
   - 先用小步 SFT（如 3000 步）确认各头损失曲线与 `belief_loss_total` 稳定，再定终值。
3. **自动化方案（可选，后续）**：
   - 用每个头损失的指数滑动平均做归一化：`w_k(t) = target_scale / EMA(L_k(t))`，让各头贡献接近 target_scale；
   - 或改为按格数/类数归一化（当前 BCE/CE 已逐格 mean，主要缺口是任务难度与类别不平衡）。
4. **wait 二判是信念价值核心**：tile 级判别关闭后可适当回调权重；仍以
   `wait_tenpai_acc` 不崩为下限，原 `0.2–0.5` 区间不再适用。

### 7.3 不与本次硬性要求混淆

- 梯度隔离（§2.1–2.3）是**结构正确性**问题，必须修；
- 损失比例（§7）是**超参调优**问题，可在隔离后单独迭代，不阻塞隔离修复。
