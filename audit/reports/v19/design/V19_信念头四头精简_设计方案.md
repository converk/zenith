# V19 信念头四头精简设计方案（2026-09-08）

## 背景与动机

第一版 V19 SFT/PPO（五头信念 + belief_public_grad_scale=0.25 耦合 + 铳点
精确回归）的 2v2 跨代对抗评测（6000 半庄，`audit/reports/v19/eval/
2v2_sft_v19_vs_v18/vs_v18_sft_2v2.json`）显示 V19 SFT 相对 V18 SFT 无优势
（队伍点差 -592，95% CI [-1479.6, +279.1] 跨 0）。用户复盘后决策对信念
网络做四点修正，并从头重训 V19 SFT 与 PPO。

## 用户决策（2026-09-08）

1. **信念监督不更新公共权重**：`belief_public_grad_scale` 0.25 → **0**。
   信念损失只更新私有的信念网络（belief_query / 1 层 backbone / 四头），
   公共 shared/backbone 只由 BC/PPO 策略梯度塑造（残差式隔离）——保证
   信念监督至少不会让策略变更坏。前向路径不变（detach+重标度 trick 的
   0.0 端点，architecture.py 已支持）。
2. **删除 shanten 头**：向听数（0..8）对局面影响小、不值得预测；是否听牌
   由 wait 头类别 0（非听）精确提供，不丢失高信息量信号。
3. **铳点损失分桶分类**：逐牌精确 Huber 回归（min(raw,24000)/24000）
   改为分桶 CE，桶边界 **1000/5000/9000/13000/17000**（原始点数），共
   **6 类**：[0,1k) / [1k,5k) / [5k,9k) / [9k,13k) / [13k,17k) / [17k,24k]。
   理由：4000 与 6000 的差异对局面影响小，精确预测给信念头带来过大压力；
   分桶后损失贡献不放大细粒度差异。桶中心 (500/3000/7000/11000/15000/
   20500) 仍生成归一化期望值 `belief_loss_expected` 供读出与摘要使用
   （取代旧 `belief_loss_pred`）。
4. **四头损失贡献均匀**：hand / wait / danger / loss_bucket 四头原始损失
   仍除以标签分布基线（熵 / 最优常数 BCE），λ_k 全 1.0；danger（逐牌）与
   wait 听牌判定保持不模糊的高信息量语义。

## 实现落点

- `riichi_ppo_v1/model/belief_network.py`：四头 + `loss_bucket_targets`/
  `loss_bucket_centers`（bucketize right=True），SUMMARY_DIM 130→121。
- `riichi_ppo_v1/model/belief_readout.py`：逐动作特征 21→18（删除
  shanten_expected，loss 项改用 belief_loss_expected）。
- `riichi_ppo_v1/training/belief.py` 与 `riichi_ppo_v1/sft/trainer.py`：
  四头损失/指标（分桶 CE + 桶精度 + 期望 MAE），与 PPO learner 同构。
- 配置：`v19_sft.yaml`（超参沿用 V18 SFT：batch 512、log 100 步、不开
  compile、验证抽样 150k）、`v19_ppo.yaml`（超参沿用 V18 PPO 正式配置：
  150 updates、熵三点 0.014/0.006/0.002 @0.33、无熵地板、critic_bootstrap
  2、torch_compile/reference 全开；minibatch 与两代一致均为 2048）；
  belief_public_grad_scale=0、四头 λ=1.0。
- 标签管线不变：shanten 标签仍在数据集/标签管线中生成但不再被模型消费
  （不重跑 precompute，不重新重标）。
- 汇报面：`belief_metric_keys`、tensorboard 键、1v3/2v2 评测信念面同步
  更新（wait_tenpai_acc / loss_bucket_accuracy / loss_expected_mae 取代
  shanten_top1 / loss_mae / loss_conditional_mae）。

## 兼容性

- 模型权重结构变化（四头 + token_matrix 121 输入）→ 旧 V19 checkpoint
  不兼容，本设计随「从头重训 V19 SFT/PPO」一起生效；旧产物按规范归档于
  `checkpoints/train_riichi_v19/archive_*/`。
- 30 信念 token 的**输入契约数量不变**（10/家），token 内容随摘要变化。
- 数据集不变（`..._encoded_60pct_v19_fuzzy`），无需重编码或重标。
