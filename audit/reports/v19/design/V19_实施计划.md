## 2. 阶段分解

### 阶段 0:契约与常量(串行前置,一切依赖它)

- `encoding_protocol.py`:schema 全量变更——删 `KIND_CRITIC_FUTURE(14)`/
  `SEGMENT_CRITIC_FUTURE(5)`/RIVER_SUMMARY;`SEGMENT_BELIEF=5`、
  `KIND_RIICHI_CARD=14`、`KIND_BELIEF=15`;立直卡 schema(训练分册 §5);
  MELD +`meld_turn(27)`+`called_tsumogiri(2)`;PLAYER/OPPONENT_ANALYSIS/
  TILE_STATE/RIVER_DISCARD 字段变更(输入分册 §3);
- 契约哈希重算;`riichi_ppo_v1/docs/v19_input_protocol.md` 新写;
- `ModelConfig`:`layers=5`、`critic_layers=1`(输入分册 D3);
- 验收:协议单测(新 v19 语义)通过,常量无残留引用。

### 阶段 1:Rust 编码器与标签 API(依赖阶段 0)

- `current_state_encoding.rs`:河区重构(删 SUMMARY 行/被鸣锚行)、
  立直卡发射、各卡字段变更(输入分册 §2/§3);
- **标签插桩(D26)**:批量观测路径内计算并导出三家标签字段
  (暗手计数/向听/待牌位集/逐牌可荣/打点/振听),复用既有 shanten/
  计分/振听部件,环境间并行由 batched step 承担;
- `native_encoding.py` 镜像同步;`critic_features.py` 删 future wall;
- 验收:Rust 单测;编码输出与 schema 逐字段对齐断言。

### 阶段 2:模型与信念网络(依赖阶段 0,可与阶段 1 并行)

- `model/belief_network.py`(新):z_pool 池化 → 隐藏层 256→512 → 五头 →
  摘要归一化(282 维);rescale trick 照 `critic_public_grad_scale` 模式
  (architecture.py:566-575 为模板);
- `architecture.py`:`_segment_map`/`_assert_structure` 更新;信念 token
  注入(分析后、query 尾窗前;tail 窗契约不变);`belief_public_grad_scale`
  实现;`ModelConfig` 默认值;
- `bridge.py`/`worker.py`:walls 链路删除;
- `parameter_count.py` 实测 ≈7,091,872;
- 验收:形状/契约单测;rescale 梯度数值验证(×0.25 只作用于 encoder 边界)。

### 阶段 3:训练侧(依赖阶段 1+2)

- `worker.py`:标签从观测字段读入;buffer/SoA 扩标签字段(~0.35 KB/行,
  位打包);
- `learner.py`:`Σλ_k·L_k + λ_c·L_wait_danger` 损失项;`belief_public_grad_scale`
  传参;`tensorboard.py`/`learner_ddp.py` 指标注册(训练分册 §5.1);
- `configs/v19_ppo.yaml`:自包含(超参沿用 D30 清单 + 训练分册 §6 信念键);
- 验收:loss 组装单测;一轮 update 的数值冒烟。

### 阶段 4:SFT 管线与数据生成(依赖阶段 1+2)

- **数据重编码**:与 V18 完全同口径(2024–2025 两年数据、60% 抽样,
  抽样参数照抄 V18 配置),协议换 V19;五头标签在编码期离线生成
  (同一 Rust 标签 API);产出 `datasets/tenhou_sft_2024_2025_encoded_60pct_v19`;
- `sft/`(trainer/data/contract):`L_BC + belief_sft_coef·Σλ_k·L_k
  (+λ_c·L_wait_danger)` 联合,`belief_sft_coef=1.0`;节奏常量不变
  (每 3000 steps 验证/保存);
- SFT eval(§5.2):五头指标 + 既有指标,最终评估 96 hanchan;
- 产出:`checkpoints/train_riichi_v19/sft`。

### 阶段 5:评测接入(依赖阶段 3)

- `evaluation/head_to_head_1v3.py`:信念指标面接入(§5.3),机制常量不动,
  标签 = 评测环境 Rust 侧同一 API;输出 `audit/reports/v19/eval/`;
- 验收:1v3 短程跑通,信念指标与对局结果并列产出。

### 阶段 6:bot 适配(依赖阶段 0–2;线上实例已停止,可修改)

- `riichi_lab_bot/` 对接 V19:编码随 Rust/Python 包自动生效;自查并适配
  `bridge.py`/`observation.py` 的观测构造与 PreparedDecision、模型加载
  (层数 3+2+1,信念随前向自动执行)、协议常量引用;`tiles_left` 等规则
  判定字段保留(非模型输入);
- **完整 MJAI 事件日志(新增需求)**:现状是遥测日志(EventRecorder)只有
  连接/扣发等元事件,MJAI 事件内容缺失,无法从日志回放一局计算指标。
  要求:从 `start_game` 起把收到的**全部 MJAI 事件**完整写入专用日志文件
  (建议每局一个 JSONL:局号/座位/时间戳/事件原文),覆盖对局全程至
  `end_game`,与既有遥测日志分离;排位开始后的所有事件不得遗漏;
- 验收:bot 本地对局冒烟(local_play);**用 MJAI 日志完整回放一局**到
  状态机、重建终局并计算指标。

### 阶段 7:测试与业务语义验收(依赖全部;**重点**)

- 单测/集成:协议/架构/信念/bridge/critic 全部迁移为 v19 语义(不留 v18 断言);
- **业务语义测试(用户强调的验收核心)**——验证"模型收到的输入 = 局面真实
  发生的",正反两个方向:
  - **正向**(输入与事实一致):构造/录制已知局面(对局回放),在决策点
    断言编码 token 与局面事实逐项一致:立直卡 vs 实际立直状态/巡目/宣言牌;
    牌河行 vs 实际打牌序列(手切/摸切标记;被鸣牌已从河中移除);MELD 行 vs
    实际副露构成与 `meld_turn`;TILE_STATE 可见性计数 vs 真实可见枚数;
    TABLE vs 场风/局/本场/供托/分数/宝牌指示;genbutsu/suji vs 规则计算;
    进张/待牌标记 vs 向听计算;critic 真手行 vs 真实手牌;信念标签 vs
    上帝视角真值;
  - **反向**(不输入不可得/错误信息):actor 路径无牌山、无里宝、无对手暗手
    泄漏;belief 输入仅公开信息(z_pool 来自共享段);标签不含未来信息
    (决策时刻反事实,无最终打点/里宝);字段值域合法(无越界 bucket);
  - 脚本落 `audit/reports/v19/scripts/`;
- 显存实测:B=2048 峰值 ≤35GB(预案:actor 单 block 梯度检查点);
- critic explained variance 不低于 V18 基线(删 future + 1 层后);
- bot 语义验收:线上交互的模型输入与训练输入同构(同一编码路径);
  MJAI 完整日志回放一局验证(阶段 6);
- 短程 SFT/PPO 冒烟:损失收敛正常、信念指标曲线正常;**冒烟产物清理**。

### 阶段 8:SFT 一体化启动脚本交付(**不启动训练**)

- 编写一条命令的一体化脚本(落 `audit/reports/v19/scripts/`,自描述命名):
  ① SFT 数据重编码(两年 60% 口径 + 离线标签生成)→ ② SFT 训练启动
  (日志落 `logs/v19/`);可重入(重编码已完成则跳过,提供 `--force`);
- 脚本正确性用最小规模自检验证(如 `--smoke` 限制局数/步数),
  自检产物清理;
- **不启动正式 SFT 训练、不启动 PPO**;向用户输出运行命令;
- `audit/reports/v19/report/PROGRESS.md` 全程记录(每阶段:改动文件、
  关键决策及理由、测试结果)。

## 3. 训练配置摘要(详见训练分册 §4.5/§6)

- PPO:**完全沿用 v18_ppo.yaml**——ppo_clip=0.20、update_epochs=2、
  target_kl=0.01(check_interval=8)、value_coef=0.3、entropy normalized
  (0.014/0.006/0.002,fraction 0.33)、分组学习率(actor 9e-5→2.25e-5 /
  shared 7.5e-6→3.75e-6 / critic 8e-5→2.25e-5 / bootstrap 2e-5)、
  warmup_fraction=0.02、sft_kl_coef 0.0025→0.001→0.0005、
  games_per_update=2048、minibatch 2048×累积 10;
- 新增信念键:belief_public_grad_scale=0.25、五头 λ_k=1.0、
  belief_wait_danger_weight=0.05、belief_sft_coef=1.0;
- ⚠️ AGENTS.md 的 `target_kl=0.0 / update_epochs=4` 是性能测试基线,
  不是训练配置,勿混用。
