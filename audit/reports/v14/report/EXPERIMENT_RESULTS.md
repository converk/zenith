# V14 PPO 实验结果（2026-08-13）

## 1. 实验目标与设置

V14 在不重训 SFT、不改 Actor 结构/Token Schema 13 的前提下，从
`checkpoints/train_riichi_v13_sft/best_heuristic.pt` 严格加载全部权重
（含完整 critic），为 Critic 增加“live wall 接下来 5 张牌”的有序特权输入：

- 阶段：update 1–40 Critic Bootstrap（actor/shared 冻结，
  `critic_public_grad_scale=0.0`，`critic_bootstrap_learning_rate=0.00002`）；
  update 41–800 Joint PPO（`critic_public_grad_scale=0.25`）。
- Reward：纯小局点棒差 `clip((score_after - score_before)/1000, -24, +24)`，
  仅 end_kyoku 发放一次，GAE 向局内传播；无 GRP/稠密效率/启发式对手。
- SFT-KL：0.02 → 0.002 线性退火；PPO `target_kl=0.02`、`ppo_clip=0.2`、
  `update_epochs=4`。
- 对手分布：70% 全 current、20% 1 席冻结 V13 SFT（greedy）、
  10% 1 席历史池 PPO（greedy）；历史池 u60+ 且滞后 ≥60，池空时回退 70/30。
- 评测：每 30 update 保存 checkpoint 后同步阻塞跑 1v3：10 进程 × 160 半庄
  = 1600 半庄，CUDA_DEVICE=0/2，model_b=best_heuristic.pt，候选席 i%4 轮转，
  greedy；汇总 2000 次 pooled bootstrap 95% CI。
- 全部单测（199 riichi_ppo_v1 + 219 RiichiEnv env + 25 lab_bot）、
  兼容性测试与 3 次 smoke 通过后启动；长训 `kyokus_per_worker=16`。

## 3. 最优 checkpoint

综合排序（分差/CI 权重更高，同时纳入一位率、前二率、均顺、四位率、和牌率、
放铳率、被自摸率、分差为正占比）：

1. **u120（checkpoint_00120.pt）**：分差 +4914（CI [+3815, +6007]），
   一位率 0.3531、前二率 0.5663、均顺 2.309 全部全场最优；和牌率 0.283、
   放铳率 0.126，攻守平衡。
2. u660（checkpoint_00660.pt）：分差 +5113（CI [+4076, +6204]）与和牌率
   0.301 全场最高，均顺 2.337；等权综合时排第一，与 u120 差距在 CI 重叠范围内。
3. u510（checkpoint_00510.pt）：防守最稳——放铳率 0.107、四位率 0.203、
   分差为正半庄占比 0.562 全场最优；分差 +4275（CI [+3300, +5292]）。
4. u240（checkpoint_00240.pt）：分差 +3553（CI [+2473, +4609]），和牌率 0.288。
5. u360（checkpoint_00360.pt）：分差 +2753（CI [+1647, +3807]），
   均顺 2.376、放铳率 0.131。

**最终推荐：checkpoints/train_riichi_ppo_v14/checkpoint_00120.pt。**

相对 SFT 基准（u000：一位率 0.2537、均顺 2.501、分差 -7.5），u120 的一
位率 +9.9pp、均顺提升 0.19、分差 +4921，且其 CI 下界（+3815）高于基准 CI
上界（+997），提升统计显著。

## 4. 风险与说明

- 曲线波动大：相邻 30-update 点之间一位率/分差存在 ±2000 分左右的震荡
  （u120→u150→u180 即 +4914→+1556→+688），单点不能代表稳定性；
  最优 checkpoint 需结合多点邻域判断。
- 后期（u600+）整体水平未见单调提升，u660 之后回落，提示当前超参
  （LR、KL 退火、历史池占比）下 800 updates 后可能进入收益递减区。
- 评测只用 greedy 行动且对手固定为 SFT 三席，未覆盖随机采样/多样对手下的
  泛化表现；未来五张墙牌作为 critic-only 特权信息仅在训练/rollout 生效，
  评测走 forward_policy，不依赖该特权输入。
- 历史池在 u120 首次启用时曾因 namespace 解析 bug 崩溃一次，修复后
  从 u90 恢复并重算 u91–u119；最终 800 updates 完整跑完，26 个 checkpoint
  与 27 份评测（含 u000 基准）全部落盘。

- 尝试更长训练/不同 KL 退火终点与 critic_public_grad_scale，确认后期收益；
- 将未来墙牌特权信息扩展到评测/部署前向路径（若允许 critic 在线上使用），
  或保持 critic-only 训练用特权、推理用公开表征的分离设计。

Holdout 结论：

- 三个候选在全新 2000 半庄上均显著优于 SFT 基准（分差 CI 下界全部高于基准
  CI 上界 +819），V14 的提升可复现，非原种子集过拟合。
- **u510 跨两套评测最稳健**：holdout 分差 +3777、前二率 0.574、放铳率 0.107
  均为三候选最优，两套平均分差 +4026 最高。
- u120 的 holdout 一位率最高（0.3155），分差两套平均 +3992，与 u510 几乎并列。
- u660 原曲线最强（+5113）但 holdout 回落最大（+2915），单点高值部分依赖
  原种子集。

**最终推荐修正：u120 与 u510 并列首选**——若优先一位率与攻击性选 u120，
若优先稳定性和防守选 u510；u660 作为原曲线强度参考，不作为跨集首选。
