# PPO 优化 Goal 实验最终结论

> 最终结论以外部评测为唯一真相：v13 SFT 2v2 240 半庄 `model_a.team_win_rate` 与
> `model_a.team_point_diff_paired_bootstrap_ci95`（2000 次 paired bootstrap）；
> 固定启发式 96 半庄一位率/分差。训练 reward 不作为成功依据。

## 0. 最终判定

**总目标未达成。** 执行 E0→E4、两个组合臂、两个补充臂与两个收尾臂（共 11 个训练实验）后，
没有任何一个 checkpoint 同时满足：

1. 2v2 240 半庄胜率 **>55% 且 paired bootstrap 95% CI 不跨 50%**（u200 口径；D 的 u350 胜率 57.1% 但 CI 跨 0）；
2. 对固定启发式 **u100 后一位率不再持续退化**（所有臂在 u100–u200 或长训后均出现 <40% 的低点）；
3. EV 不再长期为负（GRP 系列满足：value_loss ~0.02–0.03，EV 未见长期为负）。

按用户指示，本轮 goal 停止跑新实验；后续实验设计见 §6。

## 2. 各实验关键证据

### E0 基线（point-delta，200 update）

- checkpoint：`checkpoints/train_riichi_ppo_goal_e0_baseline/`。
- 2v2：u50=47.50%（CI 跨 0）、u100=55.83%（CI [272,9879] 不跨 0）、u200=53.96%（CI 跨 0）。
- 启发式：u90 峰值 51.0% → u180 谷底 31.3%（+1039）；复现「u100 后先升后降」。
- 训练：EV 后期下降（u101=0.195→u181=0.060），`sft_reference_kl` 0→0.12，立直接受率升至 70%+。

### E1 EV 门控（200 update）

- 改动：`adv_estimator=ev_gate`；200 update 中仅 u190/u198 两次 EV<0 触发门控，fallback≈1.3%，基本等价 E0。
- 2v2：u50=52.71%（CI 不跨 0）、u100=57.92%（CI 不跨 0）、u200=52.50%（CI 跨 0）。
- 启发式：u180=39.6%（+3701），比 E0 轻但仍在波动。
- 判定：部分成功；u200 未达标，且门控启用极少，提升不能归因于门控本身。

### E2 对手混合 80/20（200 update）

- 改动：20% env 中 1 席替换为冻结 v13 SFT greedy；只对 current 席记录 transition。
- 2v2：u50=49.58%（跨 0）、u100=51.04%（跨 0）、u200=56.67%（CI [-1294,9089] 跨 0）。
- 启发式：u180=42.7%（+5092）、u195=47.9%（+4004），无 E0 式深谷。
- 判定：部分成功——启发式更稳但 u200 不显著；u100 反而弱于 E0/E1。

### E3 离线 GRP 验证 + PPO A/B

- 离线验证（`e3_grp/grp_validation.json`）：val rank acc=53.4%（门槛 ≥35%）、top-2 acc=78.0%、ECE=0.025（门槛 ≤0.15）、GRP reward 与 point-delta Spearman=0.377（<0.9，非冗余）。
- **E3-b 纯 GRP（λ=1.0）**：u200=**55.83%**，diff=+5240，CI **[1152,9579] 不跨 0**——全 goal 唯一 u200 显著为正的臂；但启发式 u120=34.4%、u195=35.4%，u100 后仍退化。value_loss 从 ~0.27 降至 ~0.03。
- **E3-c（λ=0.5）**：u200=50.0%（跨 0）；启发式 u180=45.8% 为 GRP 臂中最稳。
- 判定：E3-b 部分成功（2v2 单项达标），总停止条件未达。

### E4 密集效率奖励（GRP+dense=0.03，200 update）

- 2v2：u50=47.50%、u100=56.25%（CI 不跨 0）、u200=48.13%（CI 跨 0）。
- 启发式：u120=49.0%、u150=54.2%、u180=39.6%、u195=39.6%——u120–u165 明显比 E3-b 稳，但 u180/195 仍 <40%。
- 判定：失败/无提升——dense 改善后期稳定性但没有转化为 u200 2v2 优势。

### E3b+E2 组合、补充A、补充B

- E3b+E2（GRP+20% SFT 混合，从头）：u200=50.42%（CI 跨 0）；u150/u165 出现 32.3%/31.3% 低点。失败。
- 补充A（GRP+20% 随机，从头）：u200=52.71%（CI [-3109,5449] 跨 0）；u195=52.1%（+7778）为后期最强点之一。失败/无显著提升。
- 补充B（E3-b 续训 u200→u400）：u300=48.75%、u400=52.92%（均 CI 跨 0）；u210–u390 一位率多次 29%–47%、u375 分差为负。**E3-b 的 u200 显著优势不持续。**

### 收尾C（GRP+dense=0.05，200 update，CUDA=0）

- 2v2 u200：**50.00%**、diff=+722、CI **[−3317, 4893]**（跨 0）。dense 从 0.03 提到 0.05 未恢复 u200 优势。
- 启发式：u90=52.1% → u120=43.8% → u135=52.1% → u150=44.8% → u165=49.0% → u180=51.0% → u195=36.5%。u120–u180 是全部臂中最稳的一段，但 u195 仍回落。
- 判定：失败/无提升。

### 收尾D（E4 续训 u200→u400，CUDA=2，用户指示中止于 u364）

- 2v2 u350：**57.08%**、diff=+3579、CI **[−1105, 8463]**（跨 0，不显著）。
- 启发式：u210–u270 在 43.8%–50.0% 波动 → u285=30.2% → u315=31.3% → u345=32.3% → u360=30.2%。**dense=0.03 未能阻止长训退化。**
- 判定：失败；与补充B 共同说明「继续长训」不是出路。

## 3. 最优结果

按判据拆分：

- **u200 2v2 最强**：E3-b `checkpoints/train_riichi_ppo_goal_e3_grp_reward/checkpoint_00200.pt`
  （55.83%，CI [1152, 9579] 不跨 0）——唯一满足 2v2 数值判据的 checkpoint。
- **启发式后期最稳（u100–u200）**：E2 与收尾C 各有所长（E2 u180=42.7%；C u120–u180 均 ≥43.8%），但两者都在末期出现 <40% 点（E2 u105/120=39.6%；C u195=36.5%），且 E2 u200 不显著、C u200=50%。
- **没有单一 checkpoint 同时满足两条总判据**。

## 4. 证据链总结

1. **reward 信号是有效杠杆但不是充分条件**：GRP 显著改善 u200 2v2（E3-b）并把 value_loss 降一个量级；dense 改善中期启发式稳定性（E4/C）但损伤 u200 2v2。
2. **2v2 优势与启发式稳定性存在直接冲突**：凡启发式更稳的臂（E2、E4、C、A）u200 2v2 均不显著；唯一 u200 显著的 E3-b 启发式退化最明显。组合（E3b+E2、随机混合）两头都不讨好。
3. **长训无法修复退化**：补充B（纯 GRP）与收尾D（dense=0.03）续训后启发式一位率均多次跌破 40%；D 在 u350 的 57.1% 2v2 也因 CI 跨 0 不成立。
4. **EV/价值学习**：GRP 系列 value_loss ~0.02–0.03、EV 未见长期为负；E1 门控因 EV 很少转负而几乎不触发，说明 critic 问题不是当前主要瓶颈。

## 5. 剩余风险

- 240 半庄 2v2 的 paired bootstrap CI 宽度约 ±2500–±4500 分，55%–57% 的胜率并不稳定；单次结果受种子/对手风格影响大。
- 自博弈策略与人类牌谱分布漂移后，GRP 的外推可信度下降（长期使用需用自博弈数据重训 GRP）。
- 启发式退化可能与策略过度特化（立直/攻防风格漂移）有关，本报告所有臂均未能定位到单一可修复机制。
- 本次收尾D 提前中止，u400 完整点缺失；但 u285–u360 的连续退化已足以支撑「长训不解决退化」的结论。

## 6. 下一步建议（本轮不执行，仅设计）

### 6.1 E5-a：GRP + SFT-KL 锚定（纯配置，无代码改动）

- 假设：策略向 SFT 的 KL 漂移（0→0.12）与启发式退化相关；用 KL 惩罚把策略约束在 SFT 邻域，
  同时保留 GRP 的 u200 优势。
- 配置要点：`init_model=best_heuristic.pt`、`grp_mix_lambda=1.0`、
  `sft_kl_coef_start=0.0`、`sft_kl_coef_end=0.1`（可做 0.05/0.1/0.2 三档消融）、
  `iterations=200`、`evaluation_interval_updates=30`（省时）。
- 时长估算：单卡约 4.5–5h（含 u50/u100/u200 三次 240 半庄评测）。

### 6.2 E5-b：两阶段奖励课程（纯配置，resume）

- 假设：E3-b 的 u200 优势与 dense 的中期稳定性是「信号先后顺序」问题。
- 臂1「GRP→dense」：resume `e3_grp_reward/checkpoint_00200.pt`，`dense_efficiency_weight=0.05`，再训 150–200 update。
- 臂2「dense→GRP」：resume `e4_dense_on_grp/checkpoint_00200.pt`（或 C u200），`dense_efficiency_weight=0.0`，再训 150–200 update。
- 判定同上；两臂分别在 CUDA=0 与 CUDA=2 并行，总时长约 4–5h/臂。

### 6.3 其他可选项

- E4/C + EV 门控（`adv_estimator=ev_gate`）：验证 dense 臂在 EV 转负时的韧性（预计作用有限，因为 GRP 系列 EV 很少转负）。
- 对手课程：前 100 update 全自博弈、后 100 update 混 20% 随机（需小改 worker 支持 mid-run 切换 opponent_mix）。
- GRP 重训：用自博弈产生的轨迹重训 GRP 后再接 PPO，检验外推漂移假设。
