### E0：基线复现（200 update）

- checkpoint 目录：`checkpoints/train_riichi_ppo_goal_e0_baseline/`
- 状态：完成（config: `riichi_ppo_v1/configs/goal/e0_baseline.yaml`；运行日志/评测 JSON 在 `e0_baseline/`）
- **2v2 240 半庄 vs v13 SFT（seed_base=20260730）**：

| checkpoint | team_win_rate | team_point_diff_mean | paired bootstrap 95% CI |
|---|---:|---:|---|

- **固定启发式 96 半庄一位率/分差**：u15/30 42.7%/+8053 → u90 峰值 51.0%/+8833 → u180 谷底 31.3%/+1039 → u195 44.8%/+7775。u100 后一位率出现显著波动与退化（u180 明显低于 u100 峰值）。

- **判定：基线有效（成功复现）**——复现了「u100 附近较强、随后波动/退化」「启发式先升后降」「立直过度激进」等调研现象；但 E0 自身不满足总停止条件（u200 胜率 53.96%<55%、CI 跨 0；启发式 u180 退化）。

### E1：EV 门控 / 四席组内基线（200 update）

- 状态：完成
- checkpoint 目录：`checkpoints/train_riichi_ppo_goal_e1_ev_gate/`

- **门控启用**：200 update 中仅 u190/u198 两次 EV<0（-0.060 / -0.010）触发，fallback fraction≈1.3%；其余 update EV≥0，与 E0 算法等价。

#### E3 离线 GRP（完成，验证通过）

- 首轮训练发现本地 `MjaiReplay` 不填充 `game_end_scores`，`take_grp_features()["final_ranks"]` 实际等于小局末排名（抽查 5359 小局全部相同），会导致 GRP 退化成“由当前分数猜当前排名”（首轮验证 acc=95.3%，不能作为通过证据）。
- 已改为：用每场最后一小局的 `round_end_scores` 计算最终排名作为标签（MJAI 日志无 `end_game.scores`），重新训练 20% 子集（train≈276 万行、val≈30.7 万行）。
- 验证结果（`e3_grp/grp_validation.json`）：val rank acc=53.4%（随机基线 25%，门槛 ≥35%）；top-2 acc=78.0%；ECE=0.025（门槛 ≤0.15）；GRP reward 与 point-delta reward 的 Spearman=0.377（<0.9，说明不是冗余单调映射）。**通过离线验证**，可以进入 E3 PPO A/B。
- checkpoint：`checkpoints/train_riichi_ppo_goal_grp/grp_rank_predictor.pt`
